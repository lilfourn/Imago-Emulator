# What emu-headless --digest prints for test ROMs: each screen's CRC-32,
# then those of all the sound and of the save state after the last frame.
# Recorded on macOS arm64 with `scripts/determinism/check.sh --record`;
# every other OS and CPU must print the same (PRD §7), which
# scripts/determinism/check.sh checks in CI.
#
# A case is a line `== FRAMES ROM [SCRIPT]`, the ROM in test-roms/
# (scripts/fetch-test-roms.sh) and the script beside this file, followed
# by the lines recorded for it. None of these homebrew ROMs draws in 3D.
